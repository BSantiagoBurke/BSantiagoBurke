### 🚌 Proyecto destacado — Bustix

Plataforma de compra de pasajes de bus en toda Colombia, desarrollada como proyecto final de bootcamp. Backend en NestJS con autenticación JWT por roles, modelo de datos real de viajes/asientos/rutas con reservas atómicas, pagos integrados con Stripe (checkout + webhooks) y un chatbot de atención al cliente con la API de Google Gemini.

**Demo:** https://bustix.vercel.app/ *(ambiente de test, los pagos no son reales)*
**Repo:** https://github.com/BustixPF/Bustix-Backend
